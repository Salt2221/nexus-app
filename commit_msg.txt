NexusGram: настоящий Telegram клиент на MTProto + SOCKS5

Удалён WebView (telegram_web_screen.dart).
Создан полноценный Telegram-клиент внутри NEXUS:

lib/gram/nexusgram_screen.dart — главный экран NexusGram:
- Нативная авторизация (номер + код из Telegram)
- SOCKS5: 127.0.0.1:1443 через NEXUS
- Список чатов с аватарами
- Чат с отправкой сообщений
- Пузырьки входящие/исходящие
- Выход и сброс сессии
- Заголовок "NexusGram" (синий AppBar)

lib/gram/telegram_mtproto.dart — MTProto слой:
- Socks5Client для работы через NEXUS proxy
- Telegram API через прокси
- Весь трафик идёт через локальный SOCKS5

pubspec.yaml: добавлены telegram_client, socks5_proxy
