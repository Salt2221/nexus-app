NexusGram: MTProto Native как в exteraGram/Nekogram

Архитектура изменена:
- Удалён TDLib (не подходит для Flutter Android)
- Удалён tdl_native.cpp
- Создан нативный MTProto 2.0 стек:

mtproto_native.cpp/h — как в Telegram для Android:
  - NativeByteBuffer — TL-сериализация (writeInt32/64/string/bool/vector)
  - SOCKS5 клиент с полным handshake (auth + connect + domain resolve)
  - send/receive TL-сообщений через NEXUS 127.0.0.1:1443
  - AES-IGE заглушка для MTProto 2.0 шифрования
  - Ghost Mode: hide typing/online/read receipts (как AyuGram)
  - JNI bridge для Kotlin

DpiNative.kt:
  - TDLib методы заменены на MtprotoNative:
    . mtprotoConnect(proxy, dc) — SOCKS5 через NEXUS
    . mtprotoSetGhost(enable, typing, online, recall)
  - Ghost Mode — AyuGram feature

CMakeLists.txt:
  - nexus_mtproto с zlib зависимостью (TL сжатие)

NexusGram UI:
  - Переписан на MethodChannel com.nexus.v2/mtproto
  - Ghost Mode кнопка в меню
  - Упрощённая авторизация: phone → code
